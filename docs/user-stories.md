# User Stories

1. As a new user, I want to register and select a role so that I can access the relevant functionality.
2. As a user, I want to log in with a username and password so that I can securely save my progress and data.
3. As a teacher, I want to select educational programs from the dashboard list so that I can use them to teach students.
4. As a teacher, I want to create custom educational programs so that I can share knowledge and teach students.
5. As a teacher, I want to see a list of subjects I teach in my profile so that I can quickly access them.
6. As a student, I want to browse the list of available subjects on the dashboard so that I can find areas of interest.
7. As a student, I want to choose a program and a teacher so that I can learn from a suitable specialist.
8. As a student, I want to see a list of subjects I study in my profile so that I can track my learning progress.
